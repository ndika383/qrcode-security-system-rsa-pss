Metodologi & Referensi Teknis
Sumber Data & SLI:
  • Timing dashboard bersumber dari logs/log_generate.csv dan logs/log_verifikasi.csv.
  • Latency memakai median untuk kondisi tipikal dan P95/P99 untuk tail latency.
  • Metrik latensi dibatasi jendela bergulir {{ performance_summary.meta.grade_window_days if performance_summary else 28 }} hari, mengikuti praktik Core Web Vitals (CrUX) dan error budget SRE. Tanpa jendela, satu sesi lambat mengunci grade permanen.
  • Traffic/throughput, valid-rate, dan resource server diperlakukan sebagai SLI operasional.
  • Ops/sec dashboard adalah estimasi 1 / median, bukan throughput load-test.
Target & Grade Response:
  • Generate Target Attainment = min(100%, target P95 / aktual P95 * 100).
  • Target lokal generate: P95 ≤0.2s per QR.
  • Verify grade memakai P95 permintaan interaktif dalam jendela bergulir {{ performance_summary.meta.grade_window_days if performance_summary else 28 }} hari; item verifikasi massal dikecualikan agar volume batch tidak menggeser grade.
  • Grade A (≤100ms) dan C (≤1000ms) mengikuti batas persepsi respons Miller (1968) dan Nielsen (1993): 0,1 s terasa seketika, 1,0 s menjaga alur pikir.
  • Grade B (≤300ms) adalah interpolasi internal tanpa rujukan kanonik.
  • Grade tidak ditampilkan bila sampel <{{ performance_summary.meta.min_samples if performance_summary else 20 }}: pada n kecil P95 sama dengan nilai maksimum.
Valid QR Rate & Confidence Interval:
  • Valid QR Rate = QR valid / total verifikasi.
  • Replay dihitung sebagai tidak valid, bukan error server.
  • 95% CI memakai Wilson score interval dengan z=1.96.
  • Success rate proses HTTP dilihat dari hasil Real HTTP Stress Test.
Referensi:
  • Google SRE Book - Service Level Objectives: SLI latency, error rate, dan throughput.
  • Google SRE Workbook - Implementing SLOs: penggunaan beberapa threshold untuk tail latency.
  • Miller (1968), Response time in man-computer conversational transactions, dan Nielsen (1993), Usability Engineering bab 5: batas persepsi 0,1 s (terasa seketika) dan 1,0 s (alur pikir tidak terputus) — dasar ambang Grade A dan C.
  • Chrome UX Report (CrUX): praktik jendela bergulir 28 hari untuk metrik latensi lapangan.
  • Wilson (1927) dan Brown, Cai, DasGupta (2001): interval estimasi proporsi binomial.
  • ISO/IEC 18004: spesifikasi simbol QR Code.
