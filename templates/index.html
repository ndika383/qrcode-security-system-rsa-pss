Informasi Sistem
Keamanan & Verifikasi:
  • Digital signature RSA-PSS 2048-bit dan ECDSA P-256
  • SHA-256 hashing untuk menjaga integritas data QR
  • Nonce + timestamp untuk deteksi replay secara real-time
  • Replay state tersimpan di SQLite dengan backup file nonce
  • Rate limiting & sanitasi file untuk mengurangi penyalahgunaan input
Alur Sistem Aktif:
  • Generate QR tunggal dan massal dari CSV
  • Verifikasi lewat upload file, scanner USB, kamera HP, dan batch massal
  • Mobile scan memakai URL pendek /v/<token> dan membuka hasil otomatis
  • Log generate/verifikasi dengan export Excel dan preview QR
  • Dashboard, job massal, audit log, dan stress testing untuk monitoring operasional
Konfigurasi Saat Ini:

Isi QR: URL verifikasi pendek /v/<token>

Payload server: JSON dengan data bertanda tangan digital

Algoritma pilihan: RSA-PSS 2048-bit / ECDSA P-256

Hash: SHA-256

Upload gambar QR: maksimal 10 MiB per file

Total request upload: maksimal 500 MiB

Retensi payload URL verifikasi: 30 hari

Masa berlaku timestamp QR: 7 hari
